# AWS cost notes

This file tracks the actual on-demand cost assumptions used by the project.

- EC2 t4g.large on-demand: approx. $0.0672/hr
- Root gp3 storage: approx. $0.08/GB-month
- Public IPv4: approx. $0.005/hr
- Typical study run: about $8.75/month for ~88 hours/month
- Paused state: about $2.40/month in EBS storage
